# Formula One Race Intelligence Dashboard

## Project Overview
The Formula One Race Intelligence Dashboard is a data visualization project created using Tableau Public. It explores Formula 1 race data through interactive charts to make race performance, team results, tyre strategies, and circuit participation easier to understand.

## Objectives
- Analyze driver and team performance.
- Explore race reliability and Did Not Finish (DNF) reasons.
- Examine tyre compound usage.
- Compare participation across circuits and countries.
- Explore drivers' average finishing positions.

## Dashboard Visualizations
The dashboard includes seven visualizations:

1. **Driver Performance:** Total points scored by drivers.
2. **Team Championship:** Total points scored by teams.
3. **Race Reliability:** Analysis of DNF reasons.
4. **Tyre Strategy:** Tyre compound usage across races.
5. **Circuit Participation:** Races associated with different circuits.
6. **Global Reach:** Races by country.
7. **Podium Performance:** Average finishing position by driver.
